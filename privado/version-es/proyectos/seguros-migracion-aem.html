Seguros · Migración a AEM

Fecha 2025Empresa Accenture Spain

  • Web
  • Adobe Experience Manager
  • Arquitectura de información
Cliente confidencial

Descripción

Migración de tres webs corporativas a Adobe Experience Manager y unificación en un único sitio para una aseguradora.

En qué consistió

  • Arquitectura de la información: estructura As-Is de las tres webs y To-Be de la web unificada.
  • Rediseño de componentes y experiencia según las necesidades de información.
  • Alineamiento con el cliente de diseño, requisitos y propuestas: reubicación de información transversal, colores y disposición.
  • Documentación del sistema de diseño, tokens de color y tipografía.
  • Prototipo funcional para demo al cliente y ajustes posteriores.
  • Documentación de comportamiento de componentes para desarrollo y aclaraciones sobre accesibilidad.
