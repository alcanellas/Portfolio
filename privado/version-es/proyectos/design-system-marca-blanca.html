Proyecto interno

Descripción

Creación de un sistema de diseño de marca blanca como base para proyectos futuros y propuestas rápidas a clientes, para que otros diseñadores no partan de cero cuando llega un cliente sin sistema de diseño. Desarrollado casi por completo con inteligencia artificial (Claude Code).

Parte de una base con los componentes básicos tanto de páginas web como de portales (AEM, LumApps, etc.), todos 100% configurables. Aparte, un archivo independiente reúne los componentes para el diseño de apps móviles, tanto en iOS como en Android.

En qué consistió

  • Análisis de sistemas de diseño de marca blanca.
  • Creación de un sistema completo, responsive y accesible.
  • Componentes 100% configurables, pensados para web y para portales como AEM o LumApps.
  • Archivo aparte con los componentes de diseño de apps móviles, para iOS y Android.
  • Exploración de las limitaciones de Claude Code y de los prompts adecuados para obtener el mejor resultado.
  • Refinamiento de los componentes una vez generados por Claude.
  • Variables consistentes y lógicas, pensadas para cambiarse con facilidad y reducir el tiempo de adaptación a cada proyecto.
  • Documentación completa del sistema en archivos .md, lista para pasar al equipo de desarrollo.
  • Workshops para enseñar a otros diseñadores a usarlo.

Herramientas

  • Figma
  • Claude Code

Estructura

El sistema se reparte en tres archivos interconectados, cada uno con un propósito distinto.

  • Archivo 1 de 3

    Covers & Components

    El archivo maestro de referencia. Plantillas de portada, componentes de portada de flujos (principal, secundaria, variaciones y casos límite), marcos de anotaciones y diapositivas de los workshops, todo construido mediante la API de plugins de Figma.

  • Archivo 2 de 3

    Design System

    Una librería de componentes completamente documentada para el equipo de EMEA ATC. 17 componentes, cada uno con visión general, especificaciones, accesibilidad, propiedades y un marco con la descripción para desarrollo, todo generado por el agente de documentación.

  • Archivo 3 de 3

    Diseños (archivo de trabajo)

    Donde viven los flujos de producto reales. Contiene el flujo de referencia (registro, 12 pantallas) y su documentación completa con el sistema de portadas y anotaciones, usado como resultado de referencia durante el Workshop 2.

Workshops

Dos sesiones prácticas para enseñar al equipo a utilizar los archivos.
